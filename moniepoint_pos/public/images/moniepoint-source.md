# Moniepoint logo

The original SVG is mirrored at https://commons.wikimedia.org/wiki/File:Moniepoint_Logo.svg and credited there to https://moniepoint.com/.

Downloaded on 3 October 2026. The brand website was blocked by a Cloudflare challenge, so the existing source SVG was used without redrawing the logo. Moniepoint retains its trademark rights.

`moniepoint-logo.svg` preserves the original wordmark. `moniepoint-mark.svg` changes only its viewBox to show the original square mark at navigation size. Colors and paths are unchanged.
